1. **Explicación para el usuario**

   > tokmd funciona sin conexión y sin cuenta de Anthropic. Podés contar tokens por sección y detectar qué partes de tu Markdown ocupan más.
   >
   > Opcionalmente, podés consultar el contador de Anthropic para el modelo elegido. Esto permite verificar tu estimación con el proveedor. Si no lo activás, conservás el análisis local, cuyo resultado puede diferir.
   >
   > La verificación online envía a Anthropic el contenido que se cuenta.

   La ventaja real es contar con la referencia del proveedor para un modelo concreto. **No está demostrado que el resultado sea siempre "muy superior"** al contador local.

2. **No prometer "lo que va a consumir exactamente"**

   Anthropic describe el resultado como una estimación que puede diferir ligeramente del consumo real. Además, medir un archivo aislado no determina el consumo de toda una sesión de Claude Code.

   El endpoint de conteo es **gratuito**, está disponible para los modelos activos y tiene límites de solicitudes. No aplica la lógica de caché. Verificado el **27/09/2026** en la documentación oficial:
   https://platform.claude.com/docs/en/build-with-claude/token-counting
